# Start here

1. Extract the current beta ZIP on your local Mac.
2. Double-click **EasyComp Keyboard Light Setup.app**.
3. Choose your language and continue.
4. Install/update, open the app, create a diagnostic report or uninstall from the same window.

No Terminal commands are required. Technical logs and the optional build check are under **Show details**. If Apple developer tools are missing, approve Apple's installation dialog when prompted.

Working from the source repository instead of the packaged download? Double-click **Start.command**. It builds and opens the same GUI. The older localized launchers are retained in `legacy/` for compatibility.

See [README](README.md) and [current development status](BETA-DEVELOPMENT.md). This development beta is not yet approved for release.
