# EasyComp Keyboard Light — Português

Faça duplo clique em **Instalar.command** para abrir o assistente. Não é necessário escrever comandos no Terminal. Para problemas use **Relatório de diagnóstico.command**. **Desinstalar.command** pede confirmação.

GitHub: https://github.com/EasyCompZLD/EasyComp-Keyboard-Light---For-headless-Apple-MacBook-Pro-s-with-T2-Chip

**macOS Intel T2 only.** Hardware other than MacBookPro16,1 remains experimental. Diagnostics are read-only and the user controls what is shared on GitHub.
