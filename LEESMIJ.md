# EasyComp Keyboard Light — start here

**No Terminal commands required — setup is now more user friendly.**

Extract the current beta ZIP locally, double-click **EasyComp Keyboard Light Setup.app**, choose your language and continue. Install/update, app launch, diagnostics and confirmed removal are in the same GUI.

The active development branch is `dev/beta`; the preceding published beta is `v1.2.0-beta7`. Beta7.1 integrates the MacBookPro15,4 protocol after visible minimum/off confirmation; integrated installation and full-range acceptance remain pending.

See [README](README.md), [development workflow](BETA-DEVELOPMENT.md) and [hardware acceptance](HARDWARE-ACCEPTANCE.md). Developers working directly from the checkout can use `Start.command`; normal users use the packaged Setup app.
