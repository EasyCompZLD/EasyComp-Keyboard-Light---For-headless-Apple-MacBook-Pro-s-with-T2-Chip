# EasyComp Keyboard Light — start here

**No Terminal commands required — setup is now more user friendly.**

Extract the current release ZIP locally, double-click **EasyComp Keyboard Light Setup.app**, choose your language and continue. Install/update, app launch, diagnostics and confirmed removal are in the same GUI.

Version 1.2.0 is the stable release. The active source branch remains `dev/beta`. MacBookPro15,4 backlight, idle timeout and wake response were reported working; original Touch Bar behavior remains unconfirmed. See [release scope](RELEASE-ACCEPTANCE.md).

See [README](README.md), [development workflow](BETA-DEVELOPMENT.md) and [hardware acceptance](HARDWARE-ACCEPTANCE.md). Developers working directly from the checkout can use `Start.command`; normal users use the packaged Setup app.
