# EasyComp Keyboard Light — current beta

The single working beta is `1.2.0-beta7.1` on `dev/beta`. [VERSION](VERSION) records the current version. All implemented installer, HID, timeout, Touch Bar monitor and diagnostic changes are maintained together.

See [current status, workflow and backlog](BETA-DEVELOPMENT.md), [release notes](GITHUB-RELEASE.md) and [hardware acceptance](HARDWARE-ACCEPTANCE.md). MacBookPro15,4 minimum lighting followed by off is physically confirmed in the isolated Issue #2 test. The normal installer and full brightness range still require [integration acceptance](BETA7.1-ACCEPTANCE.md). Touch Bar operation requires its own physical validation. Scheduling and the full lock policy remain on the same beta's backlog.

For published downloads, consult [GitHub Releases](https://github.com/EasyCompZLD/EasyComp-Keyboard-Light---For-headless-Apple-MacBook-Pro-s-with-T2-Chip/releases). Local preparation does not imply publication. Historical release notes are preserved in [docs/history](docs/history/).
